L先生说，时间清单¶

工具，待办清单（Todo List）¶

在清单的划分上，「AFD」方法 - 也就是三个清单：Action，Focused，Dessert。

第一个清单：执行清单（Action）¶

「颗粒度」--> 明确、简单的行动 --> 不需要思考

eg. 完成方案，包括理清逻辑、搜集数据、填充内容、制作图表、排版优化

完成文章，包括搜集论据、搜集资料、撰写大纲、准备案例、完成全文、修改

「认知负担」--> 拖延

完成的「动力」被削弱，而「阻力」却提升

大脑的逻辑：倾向于去做简单的、不需要太多思考的事情；而排斥复杂的、需要大量投入的事情。

在Todo List里细分任务，分拆到最小的操作步骤，明确「要做什么」，写具体：数量，目的，关键词

在Todo List上，专门开一个清单，将所有安排在今天的任务细化、分解，列出可以直接去执行的事项，专注在行动上

如何控制自己的念头，不要拖延 --> 专注在执行上，不给它分心的机会

第二个清单：聚焦清单（Focused）¶

对「休息」的误会：休息，就是好好睡一觉，让精神得到恢复，减少身体的负担
对于体力劳动，睡觉是最好的休息方式，因为可以让肌肉得到放松

对于脑力活动，睡觉能起到的作用是有限的
更好的方式，是调整聚焦点，切换到不同的工作上，激活大脑的另一块区域

经历一段高强度的工作之后，使感到疲劳的，并不是能量的损耗 --> 大脑在高速运行时，其耗能并没有比休息时高出很多，甚至可以说没有太大变化

使疲惫的，是对于这项工作的新鲜感减弱，导致处理它的意愿降低

人是一种极端需要「新鲜感」的事物。长时间思考同样的内容，会抑制大脑的活动，让人感到厌烦、疲倦、昏昏欲睡，乃至无法集中注意力

好的方法：在感到疲劳时，及时切换，去思考别的工作，做别的事情 — 哪怕这件事情同样也是高强度的

这个方法，叫做分段工作法（莫法特工作法）

建立一个清单，专门用来存放两个东西：

一是那些重要的、亟待解决的问题

二是正在研读和学习的论文、书籍等

当工作累了，打开这个清单，站起来走走，在脑子里思考。或者，打开之前没读完的书和论文，继续读，做笔记，整理逻辑和知识结构

一段时间，等大脑又感到疲倦，重新回去完成前面的工作

第三个清单：成就感清单（Dessert）¶

人的精神状态，总有低谷的时候，无论是「Action」还是「Focused」里面的事情，一点都不想干

做一个「Dessert」清单，在里面放一些非常简单、无需动脑、没有时间限制的小事，比如：

- reading --> typora
- xmind
- typora --> anki
- github page
- 整理文件夹

- 搜集图片
- 下载资源

- 整理书桌

当精力处于低谷、不想思考时，就打开这个清单，逐一去完成

1. 可以最大限度地利用时间，将这些不重要的小事分别做好

2. 当一项一项完成的时候，会慢慢积累「成就感」

成就感，帮助让精神状态回到正常水平

在做「Dessert」时，完全机械、无需动脑，让思维处于一个自由的状态
